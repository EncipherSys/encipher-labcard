# What Encipher does not build

- A circuit SDK or runtime
- A HIP port of cuStateVec
- `cudaq.set_target("amd")`
- A claim that an AMD GPU runs CUDA-Q
- A QPU service
- A certification of Qiskit, Aer, CUDA-Q, PennyLane, or Braket
- A hosted inventory platform that receives customer files
- Bit-identical ARM and x86 amplitudes as the oracle

The paid increment is a hashed bundle on a named machine the buyer already owns.
